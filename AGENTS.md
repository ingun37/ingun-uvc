# Repository guidance

This repository contains multiple projects:

- `streamer/`: native macOS SwiftUI capture-card inspector. Before working on this
  project, read and follow [streamer/AGENTS.md](streamer/AGENTS.md).
- `time_mapper/`: native macOS SwiftUI App. Before working on this
  project, read and follow [time_mapper/AGENTS.md](time_mapper/AGENTS.md).
- `time_mapper_lib/`: C++ video-to-game-clock mapping library. Before working
  on it, read and follow [time_mapper_lib/AGENTS.md](time_mapper_lib/AGENTS.md).
- `ocr/`: Python PP-OCRv6 process used by `time_mapper_lib/`. Before working
  on it, read and follow [ocr/AGENTS.md](ocr/AGENTS.md).

Project-specific instructions apply only to their respective project directories.
For changes that cross project boundaries, follow each affected project's guide.
